# ShaguDPS Skin

Look and number format for [ShaguDPS](https://github.com/shagu/ShaguDPS) (WoW 1.12) to match the rest of the UI.

## What it does
- Bar texture from your own UI instead of the Blizzard status bar, including a desaturated copy of the DragonflightUI cast bar (`img/dfrlbar`) so class colours stay correct
- Flat background with a 1 px border instead of the tooltip tile
- Friz Quadrata font in an adjustable size
- Large numbers shortened: 47320 → 47.3k, 1284000 → 1.28M

The addon sits on top of ShaguDPS without modifying its files. Updating ShaguDPS therefore overwrites nothing.

## Usage
`/sdui` or `/sdskin` opens the settings.

## Requirements
ShaguDPS

## Saved data
`ShaguDPS_UI_Config` (per character)
