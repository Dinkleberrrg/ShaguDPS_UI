# ShaguDPS Skin

Optik und Zahlenformat für [ShaguDPS](https://github.com/shagu/ShaguDPS) (WoW 1.12), passend zum restlichen UI.

## Was es macht
- Balkentextur aus dem eigenen UI statt der Blizzard-Statusbar, zur Auswahl u. a. eine entsättigte Kopie der DragonflightUI-Castbar (`img/dfrlbar`), damit die Klassenfarben stimmen
- Flacher Hintergrund mit 1-px-Rahmen statt der Tooltip-Kachel
- Schrift Friz Quadrata in einstellbarer Größe
- Große Zahlen gekürzt: 47320 → 47.3k, 1284000 → 1.28M

Das Addon legt sich über ShaguDPS, ohne dessen Dateien zu verändern. Ein Update von ShaguDPS überschreibt also nichts.

## Bedienung
`/sdui` oder `/sdskin` öffnet die Einstellungen.

## Voraussetzungen
ShaguDPS

## Gespeicherte Daten
`ShaguDPS_UI_Config` (pro Charakter)
